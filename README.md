# 拾光 (HyperMem) 
### 基于 MiMo-V2.5-Pro 的个人多模态记忆编排引擎

本项目旨在利用大模型的长上下文（Long-Context）能力，将个人碎片化的数字资产（实拍照片、备忘录、健康数据）转化为具有情感深度与逻辑关联的数字分身。

#### 核心技术栈
- **推理引擎**: MiMo-V2.5-Pro (Max-Context Mode)
- **架构**: Multi-Agent Orchestration (多代理编排系统)
- **技术点**: RAG (检索增强生成)、CoT (思维链推理)
